# Contributing to Curated AI Image & Video Tools

Thank you for your interest in contributing! This document provides guidelines for contributing to this curated list.

## How to Contribute

### Adding a New Tool

1. **Fork** this repository
2. **Create a branch** (`git checkout -b add-tool-name`)
3. **Add your entry** to the appropriate category in the README.md
4. **Submit a Pull Request** with a clear description

### Entry Format

Each entry should follow this format:

```markdown
| **[Tool Name](https://official-url.com)** | Brief but informative description of the tool and its key capabilities. | Pricing info | [Links](https://url.com) |
```

### Requirements for New Entries

- **Publicly available**: The tool must be accessible to the public (free or paid)
- **Official links only**: Link to the official website or repository
- **Accurate description**: Keep descriptions concise (1-2 sentences) but informative
- **Correct category**: Place the tool in the most appropriate section
- **Alphabetical order**: Add entries in alphabetical order within their category
- **Working links**: All URLs must be functional and point to the correct resource
- **Pricing info**: Include current pricing information

### What We Accept

- AI image generation tools and platforms
- AI video generation and editing tools
- Open-source AI models for image/video
- AI audio and music generation tools
- AI 3D model generation tools
- AI upscaling and enhancement tools
- AI face and avatar generation tools
- Related developer tools and APIs

### What We Do NOT Accept

- Tools that are no longer maintained or available
- Duplicate entries (check if the tool already exists)
- Tools without a working website or repository
- Spam or self-promotional entries without genuine value
- Tools that violate ethical guidelines

## Reporting Issues

### Broken Links

If you find a broken link, please [open an issue](https://github.com/awesome-ai-tools/curated-ai-image-video/issues/new?template=broken-link.yml) with:
- The tool name
- The broken URL
- The correct URL (if known)

### Suggesting a Tool

To suggest a new tool, [open an issue](https://github.com/awesome-ai-tools/curated-ai-image-video/issues/new?template=tool-suggestion.yml) with:
- Tool name and URL
- Brief description
- Category suggestion
- Why it should be included

## Code of Conduct

- Be respectful and constructive
- Focus on the quality and accuracy of information
- Help maintain the list's integrity and usefulness

## Questions?

If you have questions about contributing, feel free to [open a discussion](https://github.com/awesome-ai-tools/curated-ai-image-video/discussions) or [create an issue](https://github.com/awesome-ai-tools/curated-ai-image-video/issues).

Thank you for helping make this list better!
